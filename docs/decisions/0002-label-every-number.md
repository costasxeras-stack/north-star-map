# 0002: Label every value as reported, derived or not disclosed

**Status:** accepted, 0.1.0

## Context

Most of the useful input metrics (NURR, CURR, lessons per DAU) are not public. Filling them with estimates would look better and be dishonest.

## Decision

Show 'Not disclosed' with a proposed definition and guardrail. Derived ratios get their own label. Metrics I propose that Duolingo has not named publicly say so in the sources line.

## Tradeoff

- The tree shows fewer numbers and looks less complete
- Every number a reader sees can be checked
